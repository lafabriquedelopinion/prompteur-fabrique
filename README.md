# Prompteur La Fabrique

Prompteur en ligne de l'émission **La Fabrique de l'Opinion**.

👉 **Ouvrir le prompteur : https://lafabriquedelopinion.github.io/prompteur-fabrique/**

## Utilisation

1. Collez votre texte dans la zone « Texte à lire » (ou ouvrez un fichier `.txt`).
2. Indiquez si vous le souhaitez une durée visée, la vitesse et la taille du texte.
3. Cliquez sur **▶ Lancer le prompteur**, puis sur **▶ Lancer** : un compte à rebours de 3 secondes démarre le défilement.

Pendant la lecture : chrono et temps restant en haut, boutons Avancer / Reculer d'un paragraphe, Arrêt, vitesse, taille, miroir et plein écran.

**Raccourcis clavier** : Espace (lecture / pause) · ↑ ↓ (vitesse) · ← → (paragraphe) · + − (taille) · M (miroir) · F (plein écran) · R (début) · Échap (retour au texte).

## Mise en forme du texte

- Une ligne vide entre deux paragraphes.
- `# Titre` pour un titre de partie.
- `[PAUSE]` pour un repère de pause rouge.
- `**mot**` pour mettre un mot en couleur.

## Confidentialité

Le texte est enregistré uniquement dans le navigateur de chaque utilisateur (localStorage). Rien n'est envoyé sur un serveur.
